n8n Gmail Automation

n8n Gmail Automation is a personal automation tool written and run by a single private individual for their own use. It is not a commercial product and it is not offered to anyone else.

What it does

The tool runs on the author's own computer, on a self-hosted n8n workflow engine. It connects to one Gmail mailbox: the mailbox of the author, who is also the only user of the tool. Using the Gmail API it reads incoming messages, applies and removes labels, archives or moves messages to the trash, and sends replies, so that the mailbox stays organised without manual work.

The tool holds no account, no database and no service of its own on the internet. The only network call it makes on a user's behalf is to the Gmail API, from the author's own machine.

Who can use it

Only the author. There is no sign-up, no login page, no hosted app and no other user.
