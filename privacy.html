Privacy policy

Applies to n8n Gmail Automation, a personal tool operated by a single private individual on their own computer. Last updated: 18 November 2026.

Google data we access

Through the Gmail API, and only for the mailbox of the operator, the tool accesses the Gmail scopes it was granted: reading message content and headers, creating and modifying labels, archiving and trashing messages, reading and creating drafts, and sending messages.

How that data is used

Google user data is used for one purpose only: to sort, label, archive, delete and reply to the operator's own mail, as described on the home page. It is used for no other processing, no profiling, no advertising, no research and no machine-learning training.

Where it is stored

On the operator's own machine only, in the local database of the self-hosted n8n instance and in its local log files. Nothing is uploaded to any server the operator controls or to any server of a third party. Nothing is mirrored to another mailbox.

Who it is shared with

Nobody. There is no analytics tool, no tracker, no cookie, no advertising SDK and no third-party data processor. The data is never sold, rented or disclosed. The tool has no other users, so no data of any other person is ever processed.

Limited use

Google user data is never used to build or improve a product, never used to serve advertising, and never kept longer than the mail already kept in the mailbox itself. Access tokens are stored locally and are never transmitted anywhere except to Google's own OAuth endpoints.

Ending access

Access can be withdrawn at any moment and without notice: delete the credential in the local n8n instance, or revoke the app under myaccount.google.com → Security → Third-party access. Revoking stops all processing immediately; no copy of the data is retained outside the mailbox and the local n8n history, which the operator can delete at any time.
